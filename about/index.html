宏大历史

伟大诞生

本站建立于 2019 年，始于鄙人在某谷日报看到的有关 hexo 搭建博客的教程。当时这些给初中生的我看还是很新奇的，加上在学校打信息学竞赛，接触计算机比较多，于是在先辈的肩膀上又建起了我的地基。

脱胎于身无分文、目不识丁的初中生的本站基于 Node.js 下的 Hexo 与 NexT.Gemini 后端生成渲染，托管于 GitHub Page 静态网站，主要特性是零元购。

远大征程

2020年，鄙人恰在读初三。彼时新冠疫疾大作，学校里的人不得不各回各家了。祸兮福之所倚，这次疫情悄无声息地给予了本站发展猪突猛进的机会。网课在家，博主海纳百川，查遍各种网站，右键翻译各种说明，对博客大兴土木。这才有了本站的雏形。不得不说当年一无所知，随手乱改的背景和透明度还挺不错，沿用至今。

同时因为新电脑的到来，博客的后端也迁移到了新电脑，才能继续之前的工作。

随后便是高中的蹉跎三年（学业忙、生活丰富、居家时间少、游戏健康系统制裁），导致博客后面缺少维护，很多相关的云服务也被归档。

终于，在 2025 年暑假，博主想到借用之前的博客扩展 Web 开发相关知识，完成了旧电脑博客文件到新电脑的迁移，博客发展翻开了崭新的篇章（可喜可贺可喜可贺）！

博客具体的更新内容可参考博客日志。从中亦可窥见博主历经数年奇奇怪怪的知识洗礼，精神状态的微妙变化。

这是个什么网站？

很明显，这是一个博客。虽然说博客的风潮早已逝去，但在这个“信息时代”，谁不渴望能在互联网中有一席之地呢，有那么一个网络的自由空间似乎是一个很不错的事情。于是，怀着这种想法，我作为C++党成功经过各种瞎搞于2019年春季搭建好了这个博客，顺便也把我前端语言入了门？！！

博客，就我的理解，应该是属于某个人、某个集体乃至某个国家的网络自由空间（即使域名贵到让我不自由）。顾义思文，博主的这个博客对与博主来说是自由的，博主可以往里面放任何合法文章。而博主在各领域均有所涉猎，因此博客文章的种类不一而足，有题解、随笔、人生感悟、技术文章、文学作品等，读者们也没必要认为一个博客一定要是那种技术类文章，毕竟这只是我的开放空间嘛~

在此，我也顺便声明一下我博客的规则。本博客文学作品分类的未声明可转载引用的文章 未经博主授权 不可转载引用 以及 声明不可转载引用的文章 未经博主授权 不可转载引用，其他文章允许做非为个人利益冒充、顶用的转载引用，但请注明出处！！！如出问题，将依法追究。

最后，欢迎大家来阅读、评论我的博客哦~

  • 分类：分类分的是文章性质的种类，您可以在不同的标签，找到我不同的作品。

  • 搜索：支持文章标题及内容搜索。
  • 讨论：
    • valine：支持邮箱回复提醒，但请正确输入个人信息（注：网址那栏填的是自己拥有的网址，可填可不填）。国内访问速度较快
  • 与博主沟通：里面发送的信息会直接发送给博主的某个软件，博主会定期查看，你可以在里面对博客bug进行反馈，对博客未来的功能提供建议，甚至直接与博主在线聊天（希望您能留下联系方式）。
  • 热度排行：查看本博客里比较受欢迎的文章。
